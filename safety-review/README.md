# Safety review — ESP Light 1.1.0 draft

BENCH ONLY. Disconnect mains and physically disconnect relay control wiring. ESP32 is not a certified protective device. Do not reconnect until a qualified electrician has assessed an independent RCBO/RCCB, sensor, isolation, load and contact feedback. GPIO input/high impedance does not guarantee relay contacts are open.

Firebase draft rules are not deployed. Review actual production rules, then test in emulator using synthetic accounts before considering a release. The web UI must display monitorOnly as read-only, display alarmLatched and sensorLow separately, show latchStorageFault and stale heartbeat as unknown/fault, and never interpret reportedOn or outputVerified=false as proof of disconnection. Disable remote ON in the UI and server rules. No remote reset. The monitor must not claim it verified disconnection. Existing firmware devices remain unchanged until manually replaced; unpublishing does not stop them. No test on mains. Test at safe low voltage with relay wiring physically removed, verify boot/reboot, disconnected sensor, missing configuration, lost Wi-Fi, auth failure, NVS write failure and power interruption. A persistent alarm can be lost if flash is erased or power fails before commit; this firmware is monitoring-only and cannot guarantee safety. The sensor filter field from the prior program is retained for build compatibility only; the draft latches raw LOW immediately. SIM800L calls are best-effort, not emergency service. Review firmware build output and Firebase UI/rules before releasing. Do not publish or use this draft for energizing or protecting a mains circuit.
